# เครื่องคิดเลข GUI Python 

แอปพลิเคชันเครื่องคิดเลขแบบ GUI ที่สมบูรณ์ สร้างด้วยไลบรารี tkinter ของ Python มีอินเทอร์เฟซที่ใช้งานง่าย และคุณสมบัติการคำนวณขั้นสูง
เป็นส่วนนึงของวิชา ENGCE174 OOP (Object Oriented Programming)

## 📷 ตัวอย่างหน้าจอ

เครื่องคิดเลขมีอินเทอร์เฟซที่สะอาดและทันสมัย ประกอบด้วย:
- หน้าจอแสดงผลขนาดใหญ่ที่แสดงนิพจน์ปัจจุบันและก่อนหน้า
- ปุ่มกดที่ตอบสนองได้ดี
- โทนสีที่ดูมืออาชีพ
- รองรับการใช้งานด้วยแป้นพิมพ์

## คุณสมบัติ

###  การคำนวณพื้นฐาน
- **บวก** (`+`)
- **ลบ** (`-`)
- **คูณ** (`×`)
- **หาร** (`÷`)
- **ยกกำลัง (`^`)**

###  คุณสมบัติขั้นสูง
- **รองรับวงเล็บ**: การคำนวณนิพจน์ที่ซับซ้อนด้วยวงเล็บซ้อนกัน
- **ใช้งานด้วยแป้นพิมพ์**: รองรับการกดแป้นพิมพ์เต็มรูปแบบ
- **ประวัติการคำนวณ**: แสดงทั้งการป้อนข้อมูลปัจจุบันและประวัติการคำนวณ
- **ฟังก์ชัน Backspace**: ลบตัวอักษรทีละตัว
- **ฟังก์ชัน Clear**: รีเซ็ตการคำนวณทั้งหมด
- **การคำนวณต่อเนื่อง**: นำผลลัพธ์ก่อนหน้ามาคำนวณต่อได้
- **จัดการข้อผิดพลาด**: ข้อความแจ้งข้อผิดพลาดที่เป็นมิตรสำหรับการดำเนินการที่ไม่ถูกต้อง

###  ปุ่มลัดบนแป้นพิมพ์
- **ตัวเลข (0-9)**: ป้อนข้อมูลโดยตรง
- **เครื่องหมายคำนวณ (+, -, *, /)**: การดำเนินการทางคณิตศาสตร์
- **Enter**: คำนวณผลลัพธ์ (เหมือนปุ่มเท่ากับ)
- **Backspace**: ลบตัวอักษรสุดท้าย

### โครงสร้าง Class

#### `BaseCalculator`

- **จัดการการป้อนข้อมูลพื้นฐาน**: การรับข้อมูลตัวเลขและเครื่องหมาย
- **จัดการการแสดงผล**: อัพเดต label และนิพจน์
- **ผูกเหตุการณ์**: ปุ่มลัดบนแป้นพิมพ์

### การจัดเรียง

### การจัดการนิพจน์

##  ตัวอย่างการใช้งาน

```
ข้อมูลที่ป้อน: 15 + 25 × 2
หน้าจอแสดง: 15+25*2
ผลลัพธ์: 65
```

### การใช้วงเล็บ
```
ข้อมูลที่ป้อน: (15 + 25) × 2
หน้าจอแสดง: (15+25)*2

```

### การดำเนินการต่อเนื่อง
```
ครั้งแรก: 10 + 5 = 15
กด +: ต่อจาก 15
ป้อน: 20
ผลลัพธ์: 15 + 20 = 35
```

### การจัดการข้อผิดพลาด
```
ข้อมูลที่ป้อน: 10 / 0
หน้าจอแสดง: Error
การดำเนินการ: ล้างอัตโนมัติสำหรับการคำนวณครั้งต่อไป
```

##  การปรับแต่ง

### การเพิ่มคุณสมบัติใหม่

1. **การดำเนินการใหม่**: ขยาย dictionary `operations`
   ```python
   self.operations = {"/": "÷", "*": "×", "-": "-", "+": "+", "^": "^"}
   ```

2. **ฟังก์ชันกำหนดเอง**: เพิ่มเมธอดใน `AdvancedCalculator`
   ```python
   def square(self):
       if self.current_expression:
           result = float(self.current_expression) ** 2
           self.current_expression = str(result)
   ```

3. **การแก้ไข UI**: ปรับสี, ฟอนต์, หรือเลย์เอาต์ในส่วนคงที่

### การขยายความสามารถ

```python
# ตัวอย่าง: เพิ่มฟังก์ชันหน่วยความจำ
class ScientificCalculator(AdvancedCalculator):
    def __init__(self):
        super().__init__()
        self.memory = 0
    
    def memory_store(self):
        if self.current_expression:
            self.memory = float(self.current_expression)
    
    def memory_recall(self):
        self.current_expression = str(self.memory)
```

## 🐛 การจัดการข้อผิดพลาด

เครื่องคิดเลขจัดการสถานการณ์ข้อผิดพลาดต่างๆ:

- **หารด้วยศูนย์**: แสดงข้อความ "Error"
- **ไวยากรณ์ไม่ถูกต้อง**: จับนิพจน์ที่มีรูปแบบผิด
- **ตัวเลขล้น**: จัดการตัวเลขขนาดใหญ่อย่างเหมาะสม
- **ตัวอักษรไม่ถูกต้อง**: กรองข้อมูลที่ไม่รองรับออก

## 📱 ประสบการณ์ผู้ใช้

### คุณสมบัติการป้อนข้อมูลอัจฉริยะ
- **การคูณโดยนัย**: `2(3+4)` จะกลายเป็น `2*(3+4)` โดยอัตโนมัติ
- **ปิดวงเล็บอัตโนมัติ**: วงเล็บที่ไม่ตรงคู่จะถูกปิดโดยอัตโนมัติ
- **เครื่องหมายต่อท้าย**: ลบเครื่องหมายที่ท้ายนิพจน์
- **ผลตอบรับภาพ**: อัพเดตหน้าจอทันทีกับแต่ละการป้อนข้อมูล

### การเข้าถึง
- **ปุ่มใหญ่**: อินเทอร์เฟซที่คลิกง่าย
- **ความคมชัดสูง**: มองเห็นองค์ประกอบทั้งหมดอย่างชัดเจน
- **การนำทางด้วยแป้นพิมพ์**: รองรับแป้นพิมพ์เต็มรูปแบบ
- **การฟื้นฟูจากข้อผิดพลาด**: ข้อความแสดงข้อผิดพลาดที่ชัดเจนและรีเซ็ตอัตโนมัติ

## 🧪 การทดสอบ

### สถานการณ์การทดสอบด้วยตนเอง
1. **เลขคณิตพื้นฐาน**: ทดสอบการดำเนินการทั้งสี่แบบ
2. **ลำดับการดำเนินการ**: ตรวจสอบลำดับความสำคัญทางคণิตศาสตร์
3. **วงเล็บ**: ทดสอบการจัดกลุ่มที่ซ้อนกันและซับซ้อน
4. **กรณีพิเศษ**: หารด้วยศูนย์, ตัวเลขขนาดใหญ่มาก
5. **การดำเนินการต่อเนื่อง**: การคำนวณต่อเชื่อมกัน
6. **การป้อนข้อมูลจากแป้นพิมพ์**: ทดสอบปุ่มที่รองรับทั้งหมด
